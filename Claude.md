This repository is for solving the Cryptopals Crypto Challenges in Rust.

Primary goal:

- Complete all Cryptopals challenges

Secondary goals:

- Learn Rust
- Learn applied cryptography
- Keep solutions correct, testable, and idiomatic

Guidelines:

- Inspect existing code before proposing changes
- Map code to specific Cryptopals sets/challenges
- Prefer incremental progress
- Reuse shared helpers where sensible
- Add tests for each challenge
- Explain both the crypto reasoning and the Rust choices
- Full solutions are allowed, but explanations should still be included

Focus on:

- byte-level correctness
- XOR and encoding logic
- block cipher modes
- padding
- oracle attacks
- randomness, IVs, and nonces
- hashes, MACs, and timing issues where relevant
- clean Rust modules and error handling
